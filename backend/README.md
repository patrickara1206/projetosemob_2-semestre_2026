# API SEMOB-SCS

Na raiz do projeto, instale dependências com `.venv\Scripts\python.exe -m pip install -r backend\requirements.txt`.
Configure `backend/.env` conforme `.env.example`. Execute dentro de backend: `..\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000`.

Documentação das rotas: http://127.0.0.1:8000/docs. Use o README da raiz para iniciar frontend e backend da mesma versão.
